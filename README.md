## 🚀 Simple Inventory App (.NET)

A web-based inventory management application built using ASP.NET Core MVC.

### ✨ Features
- 🔐 Authentication (Login & Register)
- 📦 CRUD Item
- 🔍 Search & Pagination
- ⚡ AJAX Pagination (No Page Reload)
- 📊 Dashboard with Chart.js
- 🎨 Bootstrap UI

### 🛠 Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Chart.js
